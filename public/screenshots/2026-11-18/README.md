As imagens vieram de interações Playwright com a interface real compilada do frontend local em `http://127.0.0.1:4173`. A revisão base é `c642854c44ff36709e75aeb3f25a3d865640eb8c`; o worktree também tinha alterações locais não commitadas. As chamadas da API foram respondidas por um cenário sintético em memória.
